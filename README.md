## 🚀 Featured Projects
**[Dynamic Island for Rainmeter](https://github.com/itznotnelo/dynamic-island-rainmeter)**: Apple's Dynamic Island, rebuilt for Windows with Rainmeter. No cloud, no API keys, just real system media, battery and privacy state read straight off Windows.

**GAM-075 Control**: a small local app that drives my Deltaco GAM-075 keyboard's RGB lighting over its own HTTP API, including the orange flash my homelab uses for pending approvals.

**[fly-brain-tetris](https://github.com/itznotnelo/fly-brain-tetris)**: a real fruit fly brain connectome, wired exactly as biology mapped it, learns to play Tetris through reservoir computing.

**[Warenerfassung](https://github.com/itznotnelo/asia-to-go-warenerfassung)**: a barcode-scan inventory app for a real grocery store, built with a desktop wrapper so the counter doesn't need a browser tab open.
